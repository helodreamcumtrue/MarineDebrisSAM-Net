---

## Abstract
Automated underwater vision suffers from severe optical degradation, including turbidity, color distortion, and complex seabed textures. This repository evaluates whether isolating foreground debris using zero-shot binary masks generated by the **Segment Anything Model (SAM)** improves classification accuracy over raw context-rich imagery. 

Through a systematic ablation study across four configurations, our dual-stream models achieve up to **88.96% accuracy** and a balanced **0.7176 Macro F1 score**, demonstrating that while object isolation clarifies geometric boundaries, raw environmental context remains crucial for robust classification.

All models were evaluated under identical 80/20 data splits on 6 target marine debris classes (*Plastic, Glass, Metal, Cloth/Rope, Rubber, Paper*):

##  Architecture: Marine Debris Multi-Scale Attention Module (MDMAM)

The proposed MDMAM framework processes dual streams concurrently:
* **Context Stream ($F_{ctx}$):** Extracted from raw underwater RGB images using a MobileNetV3-Small backbone to generate spatial Queries ($Q$).
* **Object Stream ($F_{obj}$):** Extracted from SAM-segmented masks to provide Keys ($K$) and Values ($V$).
* **Cross-Attention Fusion:**
  $$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{C}}\right)V$$
  $$F_{fusion} = F_{ctx} + F_{att}$$
